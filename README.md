# Bike Rental Management System

A web-based bike rental application (RentABike) built with ASP.NET Web Forms, C#, and SQL Server. Users can browse bikes, check availability, and book a bike for chosen dates.

## Features
- User login and logout
- Browse available bikes with price per day
- Live availability shown on each bike (for example, "3 Left" or "Available")
- Select pickup and delivery dates and book a bike
- Booking confirmation page
- View my bookings

## Tech Stack
- C#
- ASP.NET Web Forms
- SQL Server
